# JMeter Performance - Create Users

Performance testing project using Apache JMeter.

## Description

This project contains a JMeter test plan for testing the performance of a user creation API.

## Test Plan

- `Users_TestPlan.jmx`

## Technologies

- Apache JMeter
- REST API
- JSON
- HTTP
- Git
- GitHub

## Test Scenario

The test plan performs user creation requests and validates the API responses.

## How to Run

1. Open Apache JMeter.
2. Open `Users_TestPlan.jmx`.
3. Configure the required parameters.
4. Run the test.
5. Analyze the performance results.
